# Banking Customer 360 & Loan Risk Analytics

## Project Overview
An intermediate-level Power BI portfolio project designed to analyse banking customers, loan performance, outstanding balances and credit risk.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Modelling
- Excel

## Dataset
The project uses fictional banking data across five related tables:
- Customers
- Loans
- Payments
- Branches
- Date

## Key Analysis
- Customer segmentation
- Loan portfolio analysis
- Outstanding loan analysis
- Credit risk classification
- High-risk loan exposure
- Overdue and defaulted loans
- Branch-level performance

## Power BI Skills Demonstrated
- Data cleaning and transformation
- One-to-many relationships
- DAX measures and CALCULATE
- Filter context
- KPI cards, charts and matrix visuals
- Conditional formatting

## Project Status
In Progress — Executive Overview and Credit Risk Analysis completed. Additional analysis and drill-through features are planned.
