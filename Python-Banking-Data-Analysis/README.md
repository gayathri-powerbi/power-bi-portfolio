# Python Banking Data Analysis

Banking data analysis project using Python, Pandas, NumPy and Matplotlib.



## Project Overview
This project analyzes fictional banking customer and loan data using Python. It explores loan distribution, branch performance, loan status, and default patterns.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset
A sample dataset containing 10 fictional banking customers with:
- Customer ID
- Customer Name
- Branch
- Loan Amount
- Loan Status

## Analysis Performed
1. Created a Pandas DataFrame.
2. Inspected dataset structure and data types.
3. Checked missing and duplicate values.
4. Filtered approved and defaulted loans.
5. Calculated total and average loan amounts.
6. Analyzed loan amounts by branch.
7. Counted customers by branch.
8. Analyzed approved, defaulted, and closed loans.
9. Calculated loan approval and default percentages.
10. Created PivotTables and visualizations.

## Key Business Insights
- Compared loan distribution across branches.
- Identified defaulted loan amounts.
- Analyzed loan status distribution.
- Compared branch-level lending patterns.

## Project Files
- Banking_Data_Analysis.ipynb – Python analysis and visualizations.

## Business Objective
To demonstrate how Python can help banking teams understand loan performance, identify default patterns, and make data-driven decisions.

*Note: This project uses fictional sample data for learning and portfolio demonstration.*
